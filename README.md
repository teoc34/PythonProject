# 📚 Poverty's Influence on Education in Romania

A data-driven interactive dashboard built with **Streamlit** that explores the impact of **poverty**, **GDP per capita**, and **internet penetration** on education outcomes across Romanian counties.

This project includes **data preprocessing**, **clustering (K-Means)**, **logistic regression**, **multiple linear regression**, and **visual insights**, all within a single interactive web app.

---

## 🧪 Technologies & Libraries Used

- Python 3.x
- [Streamlit](https://streamlit.io/)
- pandas, numpy
- matplotlib
- scikit-learn
- statsmodels

---

## 🧠 Key Features
## 📊 Dataset Preview
View raw data on population, poverty, GDP, graduates, and abandonment rates.

Cleaned and normalized values for consistent analysis.

## 📈 Education Metrics by Poverty Level
Data grouped into 4 poverty levels: Low, Medium, High, Very High

Shows how graduation and abandonment rates vary.

## 📉 Scatter Plot – Poverty vs Graduates
Visual analysis of how increasing poverty might be correlated with graduation rates.

Explores counterintuitive trends and hypotheses.

## 🧩 Clustering Analysis (K-Means)
Clusters counties based on 4 key indicators:

Poverty rate

GDP per capita

Graduation rate

Abandonment rate

Visual color-coded cluster map

## 🔍 Logistic Regression
Predicts whether a county has high or low school abandonment based on:

Poverty

GDP per capita

Graduation rate

Model Accuracy ≈ 67%

## 📉 Multiple Linear Regression
Predicts graduation rates based on:

Poverty

Internet penetration

GDP per capita

R² = 0.608 — Moderate to strong explanatory power

Model includes detailed regression summary via statsmodels

## 📝 Conclusion
This interactive tool highlights the complex relationships between socioeconomic factors and educational outcomes.
It helps identify counties facing similar challenges and explores the impact of investment and access on graduation rates.
